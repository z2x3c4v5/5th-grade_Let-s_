# Let's ~ 권유하기 · 듣고 따라 말하기 웹 앱

초등학교 5학년 영어(천재교육 Unit 5) **"Let's ~"** 권유 표현을 듣고 따라 말하며 연습하는 웹 앱입니다.

## 구성
- **권유 문장 25개 × 3난이도** — 초급 / 중급 / 고급
  - 초급: 교과서 수준 `Let's + 동사`
  - 중급: 어휘 수준을 살짝 높이고 1~2단어 추가 (예: `Let's go swimming this afternoon.`)
  - 고급: `Let's` 로 시작하되 어휘 수준을 더 높이고 수식어·구를 더 추가 (예: `Let's go swimming at the outdoor pool this weekend.`)
- **긍정 대답 4개** — `Sounds good.` 외 3개
- **거절 대답 4개** — `Sorry, but I'm busy.` 외 3개 (예: `Sorry, but I'm tired.`)

## 기능
- **표현 배우기** — `문장 듣기` 버튼으로 전체 문장 발음 듣기
- **단어 학습** — 문장 속 **단어를 클릭**하면 그 단어의 **뜻 풍선**이 뜨고 **발음**도 들려줌
- **대화 연습** — 무작위 권유 문장 → 마이크로 따라 말하기 채점 → 친구의 긍정/거절 대답 듣기
- 말하기 속도 조절 슬라이더
- 모던한 디자인 + 전 화면 **Comic Sans** 글꼴

## 사용한 기술
- 순수 HTML/CSS/JavaScript (빌드 불필요)
- **Web Speech API**
  - `SpeechSynthesis` : 영어 음성 출력 (별도 mp3 파일 불필요)
  - `SpeechRecognition` : 따라 말하기 채점 (Chrome 등 지원 브라우저, 마이크 권한 필요)

> 원본 데이터의 음원(mp3)/이미지(png) 파일은 저장소에 포함되어 있지 않아,
> 음성은 브라우저 음성합성으로, 그림은 이모지로 대체했습니다.

## 실행 방법
`index.html` 을 브라우저로 열면 끝입니다. 또는 로컬 서버 실행:

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

> 마이크(따라 말하기) 기능은 **Chrome 브라우저**에서 가장 잘 작동합니다.

## 파일
| 파일 | 설명 |
|------|------|
| `index.html` | 화면 구조 |
| `style.css`  | 디자인 (반응형, 모바일 지원) |
| `data.js`    | 문장 데이터 (권유 25 / 긍정 4 / 거절 4) |
| `app.js`     | 음성 출력·인식, 대화 연습 로직 |
